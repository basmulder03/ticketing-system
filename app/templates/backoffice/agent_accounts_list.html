Agent accounts

An agent account is a named API key for an AI agent or other external tool. Agent keys can read and write the same content-management surface a human admin edits in this backoffice — Events, Shows, Ticket types, an Event's Theme, and Email template content. They can never reach payment or SMTP credentials, admin user management, financial/order data, or this backoffice's audit log; those stay reachable only with a human admin session.
