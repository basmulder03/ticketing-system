{# Full-screen result overlay -- built/shown/hidden entirely by scan.js. Deliberately NOT itself an aria-live region: scan.js populates its content via appendChild while it's still `hidden`, then flips `hidden` to false as the very last step -- the well-documented "populate then unhide" anti-pattern, where several screen readers never announce anything because the content mutations happened before the region existed/was visible in the accessibility tree, and un-hiding an already-populated subtree isn't reliably treated as a live-region "update" either. Announcements instead come from the persistent `#scan-result-announcer` below, which is never hidden and only ever has its text content changed -- the same pattern this project's public site already uses (`pub-presale-announcer` / `pub-copy-announcer` in app/templates/public/*.html). #}
