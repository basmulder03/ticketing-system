# Vendored fonts

The `.woff2` files in this directory are static Regular (400) and Bold (700)
instances of the following typefaces, self-hosted so `ThemeFont`'s non-system
choices actually render instead of silently falling back (see
`app.models.enums.ThemeFont` and `app/static/fonts.css`). Each is redistributed
under its own open license, unmodified beyond Google Fonts' standard subsetting
to the Latin character set (covers English and Dutch):

| Font             | License                       |
| ---------------- | ------------------------------ |
| Inter            | SIL Open Font License 1.1      |
| Roboto           | Apache License 2.0             |
| Open Sans        | Apache License 2.0             |
| Lora             | SIL Open Font License 1.1      |
| Merriweather     | SIL Open Font License 1.1      |
| Playfair Display | SIL Open Font License 1.1      |

Source: [Google Fonts](https://fonts.google.com/). Full license texts:
[SIL OFL 1.1](https://openfontlicense.org/), [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
